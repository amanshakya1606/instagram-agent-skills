# Weekly content calendar

## Inputs
`brand/brand-profile.md` (pillars, ICP, offer), last `ig-analytics-review` output, latest `ig-viral-reel-research` notes, upcoming festivals/events in India for that week.

## Default weekly mix (adjust to capacity the user confirms)
| Day | Format | Pillar | Goal |
|---|---|---|---|
| Mon | Reel (animated, Hindi) | Education | Reach |
| Tue | Carousel | Education / framework | Saves |
| Wed | Reel | Relatable / trend | Shares |
| Thu | Carousel or single post | Proof / case study | Trust |
| Fri | Reel | Myth-busting / mistake | Reach |
| Sat | Post + Stories Q&A | Offer / behind the scenes | Leads |
| Sun | Stories only | Community | Replies |

Stories daily: 3-5 frames (poll / question / behind the scenes / repost of the day's post).

## Timing
Start with 12:30-1:30 PM and 7:00-9:30 PM IST. Once Insights exist, use "Most active times" from the account and replace these defaults.

## Rules
- Ratio: ~80% value/proof/relatable, ≤20% direct selling.
- One idea per post; each item gets one clear goal (reach, saves, shares, leads).
- Every item needs: date, time, format, pillar, working title, hook (first line / first 3 seconds), key points, CTA, asset needed, status.
- Reuse: each reel topic becomes a carousel next week and 2 stories.

## Output
Write `calendar/YYYY-Www.md` as a table plus a one-paragraph brief per item, then ask the user which items to produce first. Status values: `idea → scripted → designed → approved → published`.
