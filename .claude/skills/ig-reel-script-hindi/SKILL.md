# Hindi reel script

## Principles
- First 3 seconds decide everything: a specific claim/question + matching visual, no greeting, no logo intro.
- 20-35 seconds total (≈55-90 Hindi words of voiceover).
- One idea. A viewer should be able to say what it was about in one line.
- Write for sends: the payoff should make the viewer think of one person to forward it to.
- On-screen text carries the message with sound off; it also holds the search keyword.

## Template
```
TITLE / keyword:
GOAL: reach | saves | leads
LENGTH: ~28s

# | Time  | Voiceover (Hindi, spoken style)        | On-screen text      | Visual / animation            | SFX
1 | 0-3   | HOOK                                    | ≤6 words            | strongest visual, motion at 0s | whoosh
2 | 3-8   | Problem / stake — "kyunki..."           |                     |                                |
3 | 8-20  | 2-3 points, one per scene               | keyword per point   | icon/character/kinetic text    | pop
4 | 20-26 | Payoff / twist / result                 |                     |                                |
5 | 26-30 | CTA: send / save / DM keyword           | CTA text            | logo + handle                  |
```

## Hooks
Write 3 hooks from 3 different formulas in `brand/hooks.md`, score them with its 5-point check, keep the best, and run the script through its beat checks. Read `brand/learnings.md` for hooks that already worked or flopped on this account.

## Quick hook examples (Hindi)
- "Aapki dukaan Google pe kyu nahi dikhti? 3 wajah."
- "₹500 ke ad se ₹50,000 ki sale — possible hai? Sach suno."
- "Ye galti aapka Instagram maar rahi hai."
- "Bada brand banne ka sabse sasta tareeka."
- "Agency hire karne se pehle ye 3 sawaal pucho."

## Language
Conversational Hindi as people speak it (English business words stay English: marketing, leads, ads). Short sentences, no textbook Hindi. Write voiceover in Devanagari for the TTS and Roman for on-screen text unless told otherwise.

## Output
2 hook variants + full script table + caption line. Save to `content/YYYY-MM-DD-slug/script.md`. Next: `ig-hindi-voiceover` then `ig-animated-reel-maker`.
