# Viral reel research

Purpose: learn the pattern, then make something original. We copy structure, never the footage, script or audio.

## Find (browser)
- Search keywords: "business tips hindi", "marketing hindi", "animated explainer hindi", "motion graphics business", "startup kahani", plus ICP industries.
- Reels tab of 10-15 accounts from `brand/brand-profile.md` competitors/inspiration.
- Qualify a reel as an outlier: views ≥ 5× that account's usual views, or views ≥ 10× its follower count; posted in the last 60 days; animated/motion-graphic style.
- Collect 8-10 per session.

## Break down each reel
| Field | What to note |
|---|---|
| URL, account, views, likes, comments, date | raw numbers |
| Hook (0-3 s) | exact first visual + first on-screen words (paraphrase), hook type |
| Concept | one sentence: what idea makes it shareable |
| Structure | beats with timestamps: hook → setup → points → payoff → CTA |
| Editing | style (2D flat, kinetic text, whiteboard, character, 3D), cuts per 10 s, zooms, transitions, captions style, colours |
| Audio | voiceover gender/tone/pace, music mood, SFX use, whether it uses an Instagram library track (note the track name so it can be picked via "Use audio") |
| Length | seconds |
| Why it spread | sends? relatability? controversy? usefulness? Read top comments |

## Output
- `research/reels-YYYY-MM-DD.md` with the table.
- **Patterns**: 3-5 things the winners share.
- **5 original reel ideas** for the brand using those patterns, each with a new hook, own example, own script angle.

## Limits
- Do not download the reels or extract their audio, and do not transcribe scripts word for word.
- Voice: note the *style* (energetic, calm, storyteller) so `ig-hindi-voiceover` can pick a matching original voice — not to imitate that person.
