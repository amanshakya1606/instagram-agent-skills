# Repurpose

Only the brand's own content, or material the user has rights to. Other people's content is a reference for ideas, not a source to cut up.

## Steps
1. Read/transcribe the source. Pull out **content atoms**: each a single claim, story, number, step, objection or quote that makes sense alone. Aim for 8-15.
2. Rank atoms by usefulness to the ICP and by what `brand/learnings.md` says has worked.
3. Map the top atoms to formats:
   - strong claim / story → **reel** (`ig-reel-script-hindi`, new hook from `brand/hooks.md`)
   - process / list / framework → **carousel** (`ig-post-writer` + `ig-carousel-designer`)
   - number / quote / question → **story frame** or single post
   - common objection → **reel using formula 12 or 16**
4. Each piece must stand alone: its own hook, no "part 2", no reference to the source.
5. Slot them into the calendar across 1-2 weeks so the same topic does not appear twice in a row.

## Output
A table: atom → format → hook → day, saved in `content/repurpose-YYYY-MM-DD.md`, then production through the normal skills.
