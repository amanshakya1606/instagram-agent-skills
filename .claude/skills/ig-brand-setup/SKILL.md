# Brand setup

Goal: a complete `brand/brand-profile.md`, because every other skill writes from it.

## Steps
1. Read `brand/brand-profile.md`; list the TODO fields.
2. Only when the user allows it, open the profile in the browser and read bio, highlights, last 12 posts to pre-fill what is visible. Do not guess the rest.
3. Ask the user the missing items in one grouped message (max 6 questions at a time), in Hinglish:
   - Top 3 services you want leads for, and starting price?
   - Kis type ke client chahiye — industry, city, business size?
   - Unki sabse badi problem kya hai jo aap solve karte ho?
   - Real results / case studies / testimonials?
   - Free offer (audit, consultation)? CTA kahan — DM, WhatsApp, website?
   - Tone: professional, friendly, bold, funny?
4. Derive and write:
   - **ICP one-liner**: "We help [who] in [where] get [result] through [service]."
   - **3-5 content pillars** (e.g. Education 40%, Proof 25%, Behind-the-scenes 15%, Offer 10%, Trends/relatable 10%).
   - **Voice rules**: 5 do's, 5 don'ts, 10 phrases the brand would say.
   - **Objections list** with honest answers (price, "already have an agency", "will think", trust).
5. Save the file. Show the user a short summary and what is still missing.

## Rules
- Only real proof. If none exists, write "none yet" and let content lean on education instead.
- Never invent prices, clients or numbers.
